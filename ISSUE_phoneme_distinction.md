# Issue: Implementar distinção entre fones e fonemas

## Descrição
Na linguística existe uma diferença entre fone e fonema:

- **Fones**: são todos os sons que são pronunciados em uma língua.
- **Fonemas**: são todos os sons que são pronunciados e que mudam o sentido de uma palavra.

Podemos ter diferentes fones que não alteram o sentido da palavra.

## Solução proposta
Implementar um algoritmo que consiga comparar palavras com fones pares e verificar se a substituição dos fones altera o significado das palavras. Se a substituição dos fones pares alterar o sentido da palavra, então cada um dos fones é um fonema diferente da língua.

## Tarefas
1. Implementar detecção de fones
2. Implementar comparação de pares mínimos
3. Implementar classificação de fonemas
4. Atualizar modelo de ML para distinguir entre fones e fonemas
